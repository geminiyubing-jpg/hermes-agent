# Design Spec — 数学常数：宇宙的源代码

## Project Overview
- **Project**: 数学常数宇宙密码_ppt169_20260902
- **Canvas**: 1280×720 (ppt169)
- **Pages**: 15
- **Language**: 中文 (formula in Unicode + selective rendered)
- **Audience**: 受过通识教育的成人（非数学专业）+ 11岁资优少年延伸阅读；零基础可读
- **Positioning**: 深度科普——每个常数先讲"是什么/为什么难"，用故事+图形+类比，拒绝罗列

## Color Scheme
- bg: #0E1226 (深空蓝黑——"宇宙源代码"氛围)
- primary: #E8B84B (π金)
- secondary: #4FC3F7 (e蓝)
- accent1: #F06292 (φ粉红)
- accent2: #9575CD (i紫)
- accent3: #66BB6A (0绿)
- accent4: #FF8A65 (γ橙)
- text: #E6EAF2, dim: #8A93A8
- 每个常数一个专属色，贯穿"关系网"页

## Typography
- Title: 'PingFang SC', 'Heiti SC' bold 30-34
- Body: 'PingFang SC' 14-16, 行距1.5
- 数字/公式: 'STIX Two Math', 'Times New Roman', serif italic
- 页脚 10pt dim

## Page Structure (15页)
1. cover — 标题+七常数一瞥(七色数字卡)
2. intro — 为什么常数是"宇宙源代码"(维格纳之问引入)
3. pi — π: 圆的灵魂(阿基米德夹逼图+祖冲之)
4. pi_deep — π 的深刻性: 无理+超越+无处不在(蒲丰投针/正态分布)
5. e — e: 增长的极限(复利极限序列动画感)
6. e_deep — e^x 唯一导数=自身+自然增长家族
7. phi — φ: 完美的假象(五角星/斐波那契螺线+祛魅)
8. imaginary — i: 虚数的实在(数系扩张链+旋转90°)
9. zero — 0: 无中生有(位值制+婆罗摩笈多+微积分之0)
10. gamma — γ: 最后的谜(H_n-ln n 收敛图+未知性问题)
11. euler_identity — 欧拉恒等式: 五常数一笔连(单位圆半圈几何)
12. network — 关系网全景: 高斯积分√π/Γ(1/2)/φ=2cos(π/5)/斯特林公式
13. physics — 常数与物理世界(不确定性原理/波函数i/α=1/137)
14. philosophy — 柏拉图主义vs形式主义+人择原理
15. end — 结语金句+"常数写诗"

## Visual Principles
- 深空底+每常数专属色形成"星系"视觉隐喻
- 图形优先: 夹逼多边形/复平面旋转/收敛曲线都画出来
- 公式用 Unicode italic text(不渲染PNG, 保持可编辑), 超长公式简化
- 每页 footer: 页码 / 15
