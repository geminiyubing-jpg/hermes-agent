## 02 目录

六部分十九页。特别说明两点：第一，第Ⅰ部分是预备知识——Agent 是什么、怎么训练、记忆怎么工作，建议所有人听，就当热身；第二，底部有阅读路线——赶时间的同事看五页精华版（03/04/09/14/15），想深入的按顺序全读。今天我按全流程讲，大约五十分钟。

## 03a 预备知识一：Agent 是什么

先回答最基础的问题。左边是普通聊天机器人：你问一句它答一句，像咨询窗口，它不动手。右边是 agent：给个目标，它自己拆步骤——先思考"我该先干嘛"，然后调用工具去执行（查数据库、搜网页、改文件），执行完观察结果对不对，不对就调整再来——这个"思考、行动、观察"的循环转几百圈，直到任务完成。像新入职的审计助理：你给目标，他自己用系统、看结果、纠错重试。底下四个关键词后面反复出现：工具调用是它的"手"，回合是转一圈的单位，轨迹是完整工作底稿，奖励是任务结束的总评分。总纲一句话：Agent = 大脑（模型）+ 循环 + 工具 + 记忆。本季度所有论文都在修这套结构的某一环。

## 03b 预备知识二：怎么训练

训练 agent 主流方法叫强化学习，道理极简：让它反复做任务，做成了给奖励。问题在哪？左边的类比：学生做三百题的卷子，老师只在最后打一个总分——卷面里第 41 题做对了、第 42 题思路歪了、第 43 题蒙对了，总分 62 分，请问哪几题的方法要改？不知道。这就是"只看总分"的 outcome RL：跑完三百步任务，只收到成功或失败一个比特，哪步好哪步坏全靠猜——术语叫信用分配难题。右边的解法方向：逐题批改，也就是过程信号。本季度 HPO、MileGPO、PRM 三个流派都在造"逐题批改"。顺带认识 GRPO：同一道题让模型做十六遍，组内平均分当基准，高于平均加强、低于平均抑制——DeepSeek 发明的主流底座。为什么长任务难训：好坏动作混在一起总分一样，早期错误要到几百步后才暴露。

## 03c 预备知识三：记忆系统

Agent 的记忆分三个环节。写：什么值得记？用户说"喜欢辣的"该记，中间报错重试不该记；记多了噪音淹没信号，记少了关键信息丢——两个病都致命。管：记下的东西怎么组织？上月说用 A 银行本月改用 B，新旧冲突怎么裁决？组织形态是堆文本还是画成关系图？读：用的时候怎么找到对的记忆？取太多挤爆上下文，取太少缺信息——像调卷宗，全调来读不完，调漏了误判。最下面的图是真正的新难题：跨会话。周一说好预算上限 500，周三订了 620 的方案，下周一又推 620——错误根源在周一、暴露在下周一，单次测试根本看不到这种断层。现有基准只考"单次聊天记没记住某句话"，这就是 MemoryArena 要打假的盲区。

## 03 执行摘要

现在进入正题。季度核心矛盾一句话：前沿模型单次前向能解研究级问题，放进 agent 循环跑多小时任务却会丢决策、谎报完工、目标漂移——这个差距 8 月 7 日有了正式名字，The Horizon Gap。五大主线：长程任务定调、训练革命、记忆重构、基准重置、自我进化。底部四个数字：1547 篇综述、Ouroboros 在 Terminal-Bench 打出的 86.74%、OSWorld 2.0 的 318 次工具调用、Kimi K3 的 2.8T 开源参数。

## 04 Horizon Gap

这篇 1547 篇论文的综述是全季度定调之作。我用装修监工的类比讲它的三大失败模式。第一种，丢失早期决策：监工上午定了水管走顶不走地，下午忘了，看到工人开槽还问为啥这么开——自己定的都忘。第二种，半成品宣称完工：卫生间瓷砖贴了八成，剩一面墙没贴就汇报完工——原文叫 declaring victory on a half-finished patch。第三种，目标漂移：任务是验收厨房，中途顺手修客厅灯、研究沙发，天黑了厨房还没验。对应疗法分别是：记忆系统、完工前验证、里程碑检查点。底部核心洞察是全季度最重要的一句话：任务越长只给总分越没用，领域所有新招本质上都是在给每一步造反馈信号。

## 05 概念三分

三个都带"长"字的词必须分清。长任务是任务属性：这活儿本身要多少步——年度审计项目就是长，不管谁做都长。长上下文是模型属性：桌子一次能摊开多少材料——Kimi K3 一百万 token 就是一张巨大的办公桌。长期记忆是系统属性：档案柜好不好——今天的东西明天还在不在。常见谬误："Kimi K3 有一兆上下文所以能干长任务"——错在桌子再大也架不住干活过程不断堆新东西：要么学会丢（压缩省略），要么学会存柜子（记忆系统）。综述的第二把刀：任务承载三档——桌面内、超桌面单任务、跨任务沉淀。本季度所有论文都落在右侧两档。

## 06 HPO

训练革命第一篇。三步走，用审计复盘讲：第一步，先跑完拿到完整轨迹——项目做砸了但底稿完整，outcome RL 到这步只有"失败"俩字。第二步，事后推断意图：重读两百步，发现实际导向了"全量排查"而不是要求的"抽样审计"——这就是意图，这条路实际通向哪的事后判读。第三步，意图空间对比打分：抽样审计策略的轨迹和这条全量排查轨迹对比，每一步获得信号——这一步让你偏向了错意图，该抑制。逐题批改达成。三个结果翻成大白话：多跳任务进步最大；离线版更好——先攒一批轨迹慢慢复盘，省钱省心；不需要裁判网络也能稳。一句话总结：让 agent 学会复盘，失败轨迹本身变成教材。

## 07 MileGPO

同一战场的另一种打法，寻宝地图类比。把任务轨迹当地图：从成功轨迹里找出"每次路过都离宝藏更近"的地点，那是里程碑；从失败轨迹里找出"反复掉进去"的地点，那是陷阱——失败数据第一次成为一等公民。三步机制：挖点（让 agent 跑 N 遍标出两类点）、验真（按可信度加权：十次成功九次路过的强信号，只碰巧路过一次的弱化）、铺路（点连成图，训练时奖励靠近里程碑、惩罚靠近陷阱）。底部三代对比：Outcome RL 问赢没赢，反馈粒度整个任务一个分；PRM 每步一个分但要养个会判错的助教；MileGPO 关键节点加可信度加权，不用养助教。和 HPO 互补：一个看意图、一个看地形。

## 08 Omit 与 STAR

两篇省钱省心的。Agent-Omit 教 agent 别记流水账：改前是啰嗦模式，思考原文、工具吐回的两千字原始网页全留在记录里，越攒越厚挤爆上下文——就像底稿把每次打印的废页也订进去。改后只留关键结论，记录薄、注意力集中。方法是先教什么该省再用 RL 强化——省略本身成了可训练能力。STAR 是训练配方的对照实验：以前训 agent 全凭手感，STAR 用旅行规划测试床把五个设计变量挨个测一遍，产出配方手册。核心发现：小模型要先易后难的课程式奖励，大模型直接稀疏奖励也行。合读意义：2025 年问能不能训，2026 年问怎么训才对。

## 09 MemoryArena

记忆部分开场，全场最打脸的论文。先看旧考卷考什么："三周前我说过我女儿叫什么"——纯记忆抽查，把历史全塞检索库关键词匹配就能拿九十分。翻车在哪：换个要用记忆做决定的任务全露馅。MemoryArena 的考法是连环任务：周一定了报销上限 500 的原则，周三提交 620 的单子——agent 该记得原则主动拦下；周五第三方故意说错上限是 800——agent 该拒绝被带偏。记忆在被使用中被考核。它揪出三大隐疾：过度保留（什么都记抓不到重点）、错位遗忘（该忘的记着该记的丢了）、冲突调和失败（新旧打架不知道听谁的）。为什么方向性：它换了记分牌，从召回率换成跨会话任务完成度。

## 10 SimpleMem

老办法的痛点：全文检索像把底稿全堆桌上，每次提问都在这堆里搜相似段落，token 烧钱、搜出来的未必相关、越用越贵。SimpleMem 像档案室：第一步相似片段聚类——订机票相关的归一档；第二步小模型给每档写摘要，一段话代替全文；第三步贴意图标签——差旅类、预算类。用的时候先判断这次问题属于哪类，只调那一两段摘要，token 用量断崖式下降。结果反直觉地好：答案更准还更省钱，不用买特殊硬件。没解决的：时间先后关系。同门 EAM 一句话：把 GUI 操作画成关系图，节点是界面元素箭头是点击跳转，下次遇到类似表单直接查图上成功路径。两篇合起来的道理：记得多不如理得清。

## 11 MRAgent

范式转变：从取档案到写专题报告。老范式检索：问题来了按相似度把档案 A、B 原样搬进上下文——搬来的可能是过时的、矛盾的、无关的。新范式重构：底座是一张带时间戳的知识图——供应商、合同、付款各是节点，边记录谁连着谁、什么时候发生。查询时遍历图、挑出相关链条、现场组装一份当前问题专属的简报，矛盾已裁决、过时项已标注。像老审计员：不搬原始底稿，翻完所有资料后写一页针对本题的分析简报。在哪见效：信息打架时新说法自动压过旧说法；一环扣一环的追溯链条完整。代价是维护图要算力，简单任务别用牛刀。MemEvolve 一句话：连整理方法本身也在进化——档案室自己学会怎么当档案室。

## 12 基准重置

基准就是标准化考卷：同一套题同一把尺，分数可比进步可测。问题是考卷会被刷穿——分数逼近满分就没区分度，必须出新卷。OSWorld 2.0 就是新卷：1.0 时代是小测验，在 LibreOffice 改个表格格式，三十步几分钟，最高分刷到 85%；2.0 是全天工作——跨五个应用整理差旅报销：邮件取票据、核对政策、填单、提交，人类中位 1.6 小时，agent 平均 318 步。Gaia2 更狠：考场是活的——你查航班时航班真的会取消、同事 agent 会发消息催你、有的信息故意含糊。妙笔是每个动作可机判对错，考卷直接当训练场。DeepSWE 把交付加码：读懂容易写出难，要求五点五倍代码量。三板斧合起来都在测同一件事：Horizon Gap 补上没有。

## 13 模型军备

先扫两个盲。参数量是脑容量，2.8T 就是 2.8 万亿个可调数字，27.8B 比它小一百倍。开源权重是把大脑结构文件公开下载——可以自己部署自己微调数据不出门，银行最关心这点。三件大事：Kimi K3，两万八千亿参数首个 3T 级开源，一兆上下文原生看图，价格两块六每百万字——开源阵营第一次在长任务档位摆出旗舰。GPT-5.6 三兄弟，Sol 在 Terminal-Bench 打出 88.8%——闭源路线能力顶格但数据必须过 OpenAI 的云。最值得注意的是 OX Alpha：仅 278 亿参数打到 73 分，一年前这分数需要几百 B——小模型军团在逼近大模型防线，本地部署成本即将大降。榜单提醒：各官方披露口径，跨系统比较需谨慎。

## 14 Ouroboros

先说清 harness 这个词：模型是大脑，harness 是办公装备——工具清单怎么写、提示词怎么措辞、上下文怎么组装。同一个模型好 harness 是能干活的员工烂 harness 是实习生。Ouroboros 的自升级循环：干活 → 干活中暴露问题（工具不好用、提示词绕、低效）→ 写改进补丁过代码评审合并 → 明天的自己用升级后的装备继续干。关键：改进要过评审才能上线，是带着安全带的进化。战绩重点：模型没换都是同一个 Opus 5——Terminal-Bench 86.74% 该基准最佳、OSWorld 90.69%、连续运行 161 天不崩——提升全部来自装备自我改进。但论文自己敲了警钟：谁来评审评审标准？评审规则也在被改进的对象里，套娃隐患；161 天无人监督，方向跑偏如何回滚？进化与缰绳必须同步发展。

## 15 工业里程碑与趋势

学术外三个信号：ICML 两万四投稿创纪录，Google PAT 审了一万篇——AI 审 AI 论文本身成了 agent 应用；微软 Build 开源 ASSERT 和 ACS——agent 安全控制的标准化时刻，五个检查点卡住输入、模型、状态、工具、输出；Google 把 agent-first 写进产品哲学，token 处理两年三百倍。四条判断：一，过程信号军备竞赛白热化，Q4 大概率出现统一框架，盯 NeurIPS；二，记忆重构范式进入落地期，mem0 类产品会有升级潮；三，Gaia2 的评测即训练模式会被复制，评测集与训练场边界消失；四，自进化跑得越远治理越刚需——ACS 和 ASSERT 这类控制标准值得纳入 2027 审计规划，这是给我们内审人的落点。

## 16 尾页

论文清单全在上面，四个观察哨：NeurIPS 摄要看过程信号统一框架出现没有；OSWorld 2.0 首批分数能不能过三成；MemoryArena 榜上第一个过六成的系统；Ouroboros 类部署的公开事故报告。最后回到主题：模型很强 Agent 仍会迷路，围剿 Horizon Gap 是这个时代 agent 研究的总战役。谢谢大家。
