# 03a 预备知识一：Agent 是什么

先回答最基础的问题。左边是普通聊天机器人：你问一句它答一句，像咨询窗口，它不动手。右边是 agent：给个目标，它自己拆步骤——先思考"我该先干嘛"，然后调用工具去执行（查数据库、搜网页、改文件），执行完观察结果对不对，不对就调整再来——这个"思考、行动、观察"的循环转几百圈，直到任务完成。像新入职的审计助理：你给目标，他自己用系统、看结果、纠错重试。底下四个关键词后面反复出现：工具调用是它的"手"，回合是转一圈的单位，轨迹是完整工作底稿，奖励是任务结束的总评分。总纲一句话：Agent = 大脑（模型）+ 循环 + 工具 + 记忆。本季度所有论文都在修这套结构的某一环。
