# Design Spec — 高考物理压轴题十年全景

## I. Project
- **Title**: 高考物理压轴题十年全景：原题·思路·命题密码
- **Subtitle**: 2016-2025 真题拆解 + 出题人思路逆向工程
- **Audience**: 高三学生/物理教师/家长（懂物理的读者；公式展示完整不糊弄）
- **Format**: ppt169 (1280×720)

## II. Design System
- 底色 #F5F7FA（板书白蓝）；主色 #1A3A5C（黑板深蓝）；强调 #C0392B（红笔批注）；辅 #277653（粉笔绿）；墨 #1F2A33
- 真题卡片：白底+左侧蓝色竖线+“【原题】”标签；解题思路用“思路链”箭头图；公式用衬线体大字展示
- 每页结构：标题 → 题卡/图表 → 思路拆解 → 命题人视角框
- 页码 N / 18
