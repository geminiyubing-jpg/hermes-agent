# Design Spec — 中医 LLM APP 市场可行性分析

## I. Project
- **Title**: 「典籍智能」中医 LLM APP 市场可行性分析
- **Subtitle**: 用大模型打通古籍智慧与在线问诊的多角度可行性调研
- **Audience**: 创始团队/投资人（决策导向），内行看数据、外行看结论
- **Format**: ppt169 (1280×720)

## II. Design System
- 底色 #F7F5F0（宣纸暖白）；主色 #1F5C45（青黛绿-本草）；强调 #B3541E（朱砂橙）；辅 #C9A227（鎏金）；墨 #2B2B2B
- 字体 PingFang SC / Helvetica Neue；标题 28px 粗体；正文 13-14px；页脚 12px
- 图标：本草/卷轴意象用简单几何线条，不用emoji
- 每页结构：标题+副题 → 主体图表/卡片 → 「本页要点」深色条 → 页脚（数据等级+页码）

## III. Slide Plan (18页)
1. 封面：项目名+一句话定位+四象限关键词卡
2. 执行摘要：结论先行（可行/条件/风险三卡）+ 关键数字
3. 产品构想：三支柱（古籍知识库/LLM问答/在线问诊转诊）+ 用户旅程图
4. 市场规模 TAM/SAM/SOM：三层同心圆+数据
5. 政策环境：时间轴 2022-2026 + 红绿灯分类
6. 监管红线：AI开方禁令等 4 条红线 + 合规定位图
7. 用户画像：三类人群卡（Z世代/银发/专业人士）+ 需求-付费意愿矩阵
8. 竞争格局：22 个中医大模型三阵营地图 + 挥鞭效应
9. 对标案例 A：问止中医（亏损路径）财务拆解
10. 对标案例 B：固生堂（盈利路径）财务拆解
11. 古籍语料壁垒：语料库现状+版权要点+建库路线图
12. 技术方案：LLM 架构（RAG+知识图谱+安全规则引擎）分层图
13. 商业模式：收入结构瀑布 + 单位经济模型
14. 成本与盈利推演：3年财务模拟（保守/基准/乐观）
15. SWOT + 风险矩阵
16. 冷启动策略：三阶段 Go-to-Market
17. 里程碑与资金需求：18个月路线图 + 融资节奏
18. 结论：Go/No-Go 决策矩阵 + 三条军规
