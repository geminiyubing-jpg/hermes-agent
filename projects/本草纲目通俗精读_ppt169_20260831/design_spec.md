# Design Spec — 《本草纲目》通俗精读

## I. Project
- **Title**: 精读《本草纲目》：古文原文 × 通俗解读
- **Subtitle**: 把 400 年前的 190 万字读给今天的你听
- **Audience**: 11 岁孩子可懂的成人（老板偏好：趣味+故事+孩子能看懂，每味药不超 300 字，字体≥10pt）
- **Format**: ppt169 (1280×720)

## II. Design System
- 底色 #F7F4EC（宣纸米白）；主色 #2E5C3F（药草深绿）；强调 #A63D2F（朱批红——古代批注色）；辅 #8A6D3B（陈年墨金）；墨 #2B2620（松烟墨）
- 古文引用块：米黄底 #F5EDD8 + 左侧朱红竖线 + 竖排感排版（横排但仿古籍字体 PingFang SC + 引号「」）
- 每味药页面固定结构：原文摘录框（真古文）→ 逐句白话 → 一个故事/类比 → 现代对照条
- 页码 N / 16，页脚标注来源等级

## III. Slide Plan (16页)
1. 封面：书名+李时珍画像意象+一句话定位
2. 这是一本什么书：190万字/1892药/11096方/52卷，27年三易其稿（时间轴）
3. 怎么读它：体例八项=数据库字段（释名→附方），用甘草条目示范
4. 十六部宇宙：从水火土金石到人——分类图+林奈早200年
5. 【精读1】甘草「国老」：原文+白话+调和诸药故事+现代对照
6. 【精读2】人参的九个名字：名字里的文化史+四君子汤排兵布阵
7. 【精读3】麻黄：千古未发之秘旨——汗血同源模型+锦衣卫医案
8. 【精读4】青蒿：六个字与诺贝尔奖——1600年的接力
9. 【精读5】金石部批判：李时珍怒斥服金成仙「可谓愚也矣」
10. 【精读6】自然铜接骨：黄铁矿的前世今生
11. 李时珍的读书法：渔猎群书+正误专栏=同行评审雏形
12. 古文难字小词典：气味/主治/发明/君臣佐使 等术语白话对照表
13. 批判地读：「久服轻身延年」的迷信与真知并存
14. 它如何改变世界：达尔文引用/世界记忆名录/青蒿素流水线
15. 给读者的三把钥匙：怎么自己读原文（识典古籍等公开资源）
16. 结尾：李时珍的话+「读古书如晤古人」
