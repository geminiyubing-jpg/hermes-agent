换汇的具体过程。文本走常规分词器；图像切成 patch 向量量化对照码本；音频波形转 mel 频谱帧级编码，Qwen 的 AuT 编码器是四千万小时音频训出来的，每帧约一百六十毫秒；视频逐帧 token 化并插入显式时间戳增强时序感知。走一个具体例子：一段二百五十六乘二百五十六乘八帧的短 clip，每帧十六乘十六 patch 就是二百五十六 token，八帧两千零四十八个视频 token，加十六个文本 token——两千零六十四个 token 的同质序列，无图像模型交接、无投影胶水，注意力均匀覆盖一切。带来四个质变：读写对称（旧式只进不出）、跨模态记忆连续（多轮对话里图声音问题互相看见）、扩展变便宜、提示保真度上升。代价是 token 账单暴涨——长上下文效率成了下一个瓶颈。
