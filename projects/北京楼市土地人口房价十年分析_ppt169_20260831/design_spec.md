# Design Spec — 北京楼市十年：土地×人口×房价

## I. Project
- **Title**: 北京楼市十年深析：土地×人口×房价（2016-2026）
- **Subtitle**: 缩量提质时代的结构与分化
- **Audience**: 银行内审专业人士（数据敏感型读者），兼顾家庭置业决策参考
- **Format**: ppt169 (1280×720)
- **Pages**: 10

## II. Color Scheme
- bg: #F7F5F0（暖米白，纯色）
- primary: #8C1F28（故宫红——深研主题色）
- accent: #C9A227（琉璃金）
- ink: #2B2B2B / sub: #6B6B6B
- chart line A(土地): #8C1F28 / chart line B(人口): #4A7BA6 / chart line C(房价): #C9A227
- positive: #2E7D5B / negative: #B3541E

## III. Typography
- Title: 'PingFang SC', 'Heiti SC', sans-serif, 34-40px bold
- Body: 'PingFang SC', sans-serif, 13-15px, 行距1.5
- Data emphasis: 'Helvetica Neue', 'PingFang SC', 20-28px bold
- 最小字号 ≥10pt（用户铁律）

## IV. Icon Style
tabler-filled 线性图标，主色描边，少而精（每页≤4个）

## V. Page Structure（10页）
1. **P01 封面** — 标题+副标题+三线缩略示意+日期
2. **P02 十年总览仪表盘** — 6个KPI大数字卡片（出让金峰值/累计/宗数-62%/楼面价+173%/人口+0.3%/二手+16%）
3. **P03 土地出让金十年曲线** — 柱状图2015-2025+三阶段标注（狂飙/平台/缩量提质）
4. **P04 供给结构：宗数暴跌 vs 单宗均价** — 双轴对比+城六区占比50%
5. **P05 人口：玻璃天花板** — 折线2172.9→2180+疏解/七普两阶段标注+退休潮预警
6. **P06 房价：一轮完整周期** — 双线（新房/二手）2016-2026，峰值70325→当前45855回撤35%
7. **P07 区域分化：土地市场梯队** — 2025各区成交金额条形图（海淀448/朝阳311/丰台128/通州122/昌平117）+溢价率标注
8. **P08 区域分化：房价回到哪一年** — 分区"回撤年"表格+当前挂牌价对比（西城15.4万↔顺义2.7万）
9. **P09 剪刀差：面粉追上面包** — 地价/房价比值曲线32%→89%+三重含义解读
10. **P10 结论与展望** — 三线联动逻辑图+8·28新政耦合+2027预测（80%概率）+风险提示

## VI. Chart Approach
全部手绘SVG原生图表（柱/线/条/双轴），坐标精确计算，不使用位图。
参考 charts_index 的 CHART_STYLE_GUIDE 配色规范。

## VII. Image Usage
无位图依赖——纯数据可视化SVG图表+几何装饰。封面用抽象天际线几何剪影（SVG path手绘）。

## VIII. Image Resource List
（无——全部SVG原生绘制）

## IX. Voice & Tone
专业冷静、数据密度高、判断明确。每页有"本页要点"结论条。面向银行审计读者的严谨表达，注明数据等级。

## X. Notes
- 数据源标注于每页页脚（A/B+/C分级）
- 铁律：不凑页数、每页有实质内容、字体≥10pt、纯色柔和背景、可编辑图表
