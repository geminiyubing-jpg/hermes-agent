# Design Spec — 黄金百年价值趋势 × 五资产对比

## I. Project
- **Title**: 黄金百年：价值趋势与五资产大对比
- **Subtitle**: 1926-2026 美元·美股·核心城市房产·比特币的世纪同台
- **Audience**: 投资者/对宏观资产配置感兴趣的读者（数据密集，判断有据）
- **Format**: ppt169 (1280×720)

## II. Design System
- 底色 #FAF8F2（金箔米白）；主色 #8A6D1F（千足金）；强调 #1F3A5C（美元蓝）；辅 #B3541E（砖红）；比特币橙 #F7931A；墨 #2B2620
- 图表：金价主曲线贯穿全篇；对比资产用各自代表色；关键事件竖线标注
- 每页：标题 → 主图/表 → 「本页结论」深色条 → 页脚来源等级+页码
- 页码 N / 20

## III. Slide Plan (20页)
1. 封面：百年金价曲线剪影 + 五资产图标 + 核心数字卡
2. 执行摘要：五个世纪判断 + 一张总览表（百年收益率/波动/最大回撤/实际收益）
3. 黄金百年时间轴：1920-2026 十大里程碑（金本位→尼克松冲击→2026实际新高）
4. 百年金价全景图（对数刻度折线 + 四时代分区）
5. 第一时代 1920-1933：金本位——黄金不是商品是「价格的定义」
6. 第二时代 1933-1971：从6102行政令到布雷顿森林——黄金的管制与固定
7. 第三时代 1971-1999：自由市场的狂喜与幻灭（850→252）
8. 第四时代 2000-2026：三轮牛市（2001-11 +659% / 2013-15盘整 / 2019-26新王）
9. 黄金的命门：实际利率机制（1980沃尔克 vs 2020负利率对照）
10. 美元百年：购买力 -97% 的镜像故事
11. 对比① 黄金 vs 美元：+21000% 与 -97% 是同一枚硬币
12. 对比② 黄金 vs 美股：百年7550倍 vs 217倍——复利之王的含金量
13. Dow/Gold 比率百年：1.29盎司(1980) 到 40盎司(1999) 的钟摆
14. 对比③ 黄金 vs 核心城市房产：Manhattan 百年美元+10000%/黄金仅+25%
15. 房产黄金计价深剖：Case-Shiller/黄金比率 + London/纽约案例
16. 对比④ 黄金 vs 比特币：5000年 vs 15年——两种「硬货币」的对话
17. 比特币五轮周期表：-94%~-50% 的波动 vs 黄金 -70% 的最深回撤
18. 央行购金新纪元：2022 起 1000吨+/年 与去美元化
19. 五资产配置光谱：风险/收益/相关性定位图 + 三个组合示例
20. 结论：百年启示录（五条定律 + 2026 站位的冷静判断）
